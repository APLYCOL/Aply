# APLY — sitio completo para GitHub Pages

Sitio estático: no requiere instalación ni compilación.

## Publicar
1. Descomprime el ZIP.
2. Sube **el contenido** de esta carpeta a la raíz de tu repositorio. `index.html` debe quedar en la raíz, junto con los CSS, JavaScript, imágenes y otras páginas HTML.
3. En GitHub entra en Settings → Pages → Build and deployment.
4. Selecciona Deploy from a branch, rama main, carpeta / (root), y guarda.

## Contenido
Incluye inicio, servicios, proyectos, acabados arquitectónicos, páginas de detalle y estilos adaptables para celular y tablet. La navegación utiliza rutas relativas para funcionar también bajo el nombre del repositorio.

Se conserva la versión del sitio recuperada del commit a7a706432eba9a4e90d799284e2bc678b215fa21, con el nuevo logo suministrado por el usuario. La exportación no modifica el sitio publicado.

Las fotos y logos de clientes que aparecen como espacios reservados todavía necesitan sus imágenes reales. El formulario de contacto no tiene servicio de envío conectado; GitHub Pages solo sirve archivos estáticos.

## Editar
- index.html: secciones principales y contacto.
- proyecto-*.html: proyectos.
- servicio-*.html: servicios.
- acabado-*.html y acabados-arquitectonicos.html: acabados.
- styles.css y responsive.css: diseño y adaptación de pantallas.
- site.js y responsive.js: navegación e interacciones.
- aply-logo.png: nuevo logo.
